# Infrastructure & Hébergement Pro Web (SSOT)

## 1. Hébergement Physique & Cloud
Tous les sites et objets Pro Web sont exclusivement hébergés sur l'infrastructure cloud haute disponibilité de Propulse Lab chez Amazon Web Services (AWS) :
- **Région principale** : Europe (Irlande) — `eu-west-1`
- **Stockage & Distribution** : Amazon S3 (chiffrement AES-256) + Amazon CloudFront (CDN mondial avec terminaison SSL TLS 1.3)
- **Gestionnaire DNS** : Amazon Route 53 (Anycast mondial)
