# Glossaire Métier Propulse Lab

Ce glossaire définit les termes utilisés par les équipes Édito, Acquisition et Tech afin que l'IA comprenne immédiatement le vocabulaire du partenaire.

| Terme / Acronyme | Définition | Outil associé |
|---|---|---|
| **LP (Landing Page)** | Page d'atterrissage dédiée à la conversion (inscription newsletter, présentation d'offre, téléchargement de dossier). | `Pro Web Page Creator` / `Pro Web Uploader` |
| **Page Statique (STATIC)** | Page HTML/CSS/JS autonome hébergée et servie sur un sous-domaine ou chemin dédié via Pro Web. | `Pro Web Uploader` (`./ppl static`) |
| **GTM (Google Tag Manager)** | Conteneur de suivi analytics propre à chaque partenaire (`GTM-XXXXXXX`). Ne doit jamais être altéré ni supprimé d'une page. | `Pro Web Page Creator` |
| **Business Unit (BU)** | Marque ou pôle éditorial au sein d'un partenaire (ex. *Sain au naturel*, *Citadelle Suisse*, *IA Visionnaire*), référencé dans la fiche de chaque produit (`sku`). | `donnees-business/<sku>/fiche-produit.md` |
| **Design System / Brandkit** | Charte graphique d'un produit ou d'une marque : palette de couleurs, typographies, boutons (CTA) et composants visuels autorisés. | `donnees-business/design-system.md` |
