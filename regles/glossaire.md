# Glossaire Métier Propulse Lab

Ce glossaire définit les termes utilisés par les équipes Édito, Acquisition et Tech afin que l'IA comprenne immédiatement le vocabulaire du partenaire.

| Terme / Acronyme | Définition | Skill / Fichier associé |
|---|---|---|
| **Objet Pro Web (`PAGE` / `DOCUMENT`)** | Entité hébergée sur un site Pro Web et identifiée par sa `key` (ex. `pages/<slug>`, `leads/<slug>`, `cadeau/<slug>`). Un objet `PAGE` est une page HTML ; un objet `DOCUMENT` est un fichier binaire (PDF, image). | `skills/pro-web` |
| **LP (Landing Page)** | Page d'atterrissage HTML (`type: "PAGE"`) dédiée à la conversion (inscription newsletter, présentation d'offre, téléchargement de dossier), embarquant `headerTools.js`, `preserveParamsV2.js` et le conteneur GTM. | `skills/pro-web` |
| **`headerTools.js` & `preserveParamsV2.js`** | Scripts officiels Pro Web hébergés sur `https://cdn.info-contenu.io/assets/` : `headerTools.js` expose `getParameterByName(name)` et `preserveParamsV2.js` propage automatiquement les paramètres d'URL (`utm_*`, `leadcode`, `salescode`, `bdc`, `urlBdc`) sur tous les liens `<a href>` vers le bon de commande. | `skills/pro-web` |
| **Pro Acquisitions** | Plateforme centrale Propulse Lab (`https://pro-acquisitions.propulse-lab.com`) permettant aux partenaires de créer et administrer directement leurs listes de diffusion, formulaires LeadBox et leadcodes de captation d'abonnés (zéro dépendance CRM externe ou Salesforce). | `skills/pro-web/variables.md` |
| **Leadcode** | Identifiant de liste d'acquisition (ex. `GP18EXTPTFSIWGEN1GENALL`), créé en self-service par le partenaire sur **Pro Acquisitions**. **Règle d'or** : le leadcode réel est historiquement transmis dans les paramètres d'URL (`?leadcode=...`) lors des campagnes et **écrase automatiquement** (`override`) la valeur du formulaire. La valeur en dur n'est qu'un repli (fallback) pour le trafic direct sans paramètre. Un leadcode manquant ne doit jamais bloquer une mise en ligne. Ne jamais renvoyer vers Salesforce ni vers une équipe CRM. | `skills/pro-web/variables.md` |
| **GTM (Google Tag Manager)** | Conteneur de suivi analytics propre à chaque partenaire (`GTM-XXXXXXX`), documenté et **prérempli** dans `skills/pro-web/variables.md`. L'IA l'injecte systématiquement et automatiquement dans toute nouvelle page sans jamais demander son identifiant à l'utilisateur. Ne doit jamais être altéré ni supprimé d'une page existante. | `skills/pro-web/variables.md` |
| **Types de Sites Pro Web** | Catégorie d'hébergement d'un site dans Pro Web : `STATIC` (site statique dédié aux LPs/objets), `BLOG` (site éditorial), `PREMIUM` ou `PREMIUM_CONNECT` (espace membre / publication). | `skills/pro-web` |
| **Business Unit (BU)** | Pôle ou enseigne éditoriale au sein d'une organisation partenaire, référencé dans la fiche de chaque produit (`donnees-business/<sku>/fiche-produit.md`). | `donnees-business/<sku>/fiche-produit.md` |
| **Design System / Brandkit** | Charte graphique d'un partenaire et de ses publications : palette de couleurs, typographies, boutons (CTA) et composants visuels autorisés. | `donnees-business/design-system.md` |
| **Daily (Newsletter Quotidienne)** | Édition quotidienne déclinée en 2 volets coordonnés : **① Daily (Email)** dans Marketing Cloud (`freeformblock #195` + `templatebasedemail #207`) et **② Article sur le blog** (`BLOG` WordPress ou `STATIC` Pro Web). | `skills/pro-daily` |
