# Prérequis Techniques (100 % API, Zéro Dépendance)

1. **`git` et `curl`** : installés nativement sur macOS, Linux et Windows 10/11.
2. **Un navigateur web** (Chrome, Safari, Brave, Edge) pour prévisualiser vos fichiers HTML en local avant publication.
3. **Vos clés API** renseignées dans le fichier `.env` à la racine de votre dépôt partenaire :
   ```env
   PRO_WEB_API_KEY=votre_cle_api_ici
   # Optionnel — uniquement pour l'outil daily-publisher (Email Marketing Cloud + Blog WordPress) :
   SFMC_SUBDOMAIN=mc...
   SFMC_ACCOUNT_ID=...
   SFMC_CLIENT_ID=...
   SFMC_CLIENT_SECRET=...
   WP_APP_USER_<LISTE>=...
   WP_APP_PASSWORD_<LISTE>=...
   ```
4. **Un assistant IA disposant d'un accès terminal local** : Claude Code, Cursor, Windsurf ou Google Antigravity (les fichiers `CLAUDE.md` et `AGENTS.md` à la racine du dépôt partenaire chargent automatiquement `./RULES.md` et `./ROUTER.md`).
