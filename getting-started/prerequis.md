# Prérequis Techniques — Pro-Pilot

Pour utiliser le socle et les outils Pro-Pilot, votre environnement doit disposer de :

1. **Git 2.30+** : `git --version` (pour synchroniser le dépôt et `.pro-pilot/`)
2. **Clé API Pro Web (`PRO_WEB_API_KEY`)** : renseignée dans le fichier `.env` à la racine du dépôt partenaire (jamais committé).
3. **Assistant IA ou Éditeur** : Claude Code, Cursor, ChatGPT, Grok ou Antigravity.
