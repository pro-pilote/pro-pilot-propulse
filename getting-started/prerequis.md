# Prérequis Techniques — Pro-Pilot

Pour utiliser le socle et les outils Pro-Pilot, votre environnement doit disposer de :

1. **Python 3.9+** : `python3 --version`
2. **Git 2.30+** : `git --version`
3. **Éditeur de code moderne** : VS Code, Cursor ou terminal avec Claude Code.
4. **Clé API Pro Web** : fournie par Propulse Lab (`export PRO_WEB_API_KEY="..."`).
