# Outil : Bi-Brother (Outil DATA & Analyse de Performance)

## 1. Objectif
Consulter et structurer les indicateurs de performance (taux de conversion des LP, inscriptions webinaires, ventes par code source `SRC`) pour guider les optimisations du partenaire.

## 2. Bonnes Pratiques
- Toujours relier une analyse de performance au produit et au type de page (`donnees-business/<sku>/`).
- Enregistrer uniquement les synthèses d'apprentissage dans le dépôt Git du partenaire (les séries brutes de données restent dans Bi-Brother / Pro Web).
