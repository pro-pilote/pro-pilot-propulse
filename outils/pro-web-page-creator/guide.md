# Guide Pas à Pas — Pro Web Page Creator

Ce guide détaille les étapes de construction et modification d'une page HTML/CSS :

1. **Extraction de la promesse** : Lire la fiche produit correspondante dans `donnees-business/<sku>/fiche-produit.md`.
2. **Application de la charte** : Appliquer les tokens et variables définis dans `donnees-business/design-system.md`.
3. **Respect des blocs protégés** : Ne jamais supprimer `<!-- PPL:FORM -->` ni les conteneurs de tracking.
4. **Validation du rendu** : Tester avec `ppl static preview` sur mobile (375px) et desktop (1280px).
