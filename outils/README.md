# Catalogue des Outils Autorisés — Pro-Pilot

Ce répertoire contient les spécifications et guides des outils mis à disposition des partenaires :

1. **`pro-web-page-creator`** : Conception et édition de pages web statiques (Landing Pages, fiches produits, pages de capture) respectant la charte graphique du partenaire et les marqueurs protégés.
2. **`pro-web-uploader`** : Gestion du cycle de vie des sites statiques (miroir local, prévisualisation locale, contrôle pré-vol dry-run et publication sécurisée sur S3/CloudFront via l'API Pro Web).
